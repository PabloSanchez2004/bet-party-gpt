# Bet Party

SPA estática sin backend que permite crear y gestionar "parties" de apuestas sociales entre amigos. Todo se ejecuta en el navegador (sin servidor ni base de datos), ideal para demos rápidas.

## Cómo usar

1. Abre `bet_party/index.html` en tu navegador.
2. Elige **Crear una Party** para configurar horarios y ser administrador o **Unirse** si ya tienes código.
3. Añade jugadores, crea preguntas y deja que cada participante vote seleccionando su usuario.
4. Cuando termine la noche, el administrador marca los hechos reales y la app calcula cuotas y puntos automáticamente.

Se incluye una party demo precargada para explorar la interfaz al abrir la página.
